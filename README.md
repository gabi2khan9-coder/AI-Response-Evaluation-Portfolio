# # AI Response Evaluation Portfolio

## Overview

This repository showcases my ability to evaluate responses generated by Large Language Models (LLMs) such as ChatGPT, Claude, and Google Gemini.

The goal of this project is to demonstrate a structured evaluation process by comparing AI-generated outputs across multiple quality dimensions.

## Evaluation Criteria

Each response is evaluated using the following criteria:

- Accuracy
- Instruction Following
- Clarity
- Grammar
- Overall Quality

## Methodology

For each prompt:

1. Generate responses from multiple AI models.
2. Compare each response objectively.
3. Evaluate each criterion independently.
4. Select the strongest response based on overall performance.
5. Document observations and reasoning.
